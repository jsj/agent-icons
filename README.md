# Agent icons

A small, public collection of coding-agent logos for use in GitHub READMEs.

## Usage

Use an immutable jsDelivr URL pinned to a commit:

```html
<img src="https://cdn.jsdelivr.net/gh/jsj/agent-icons@COMMIT/claude.svg" width="18" height="18" alt="Claude">
```

Available icons:

- `antigravity.svg`
- `claude.svg`
- `codex.svg`
- `cursor.svg`
- `github-copilot.svg`
- `grok.svg`
- `openai.svg`
- `opencode-logo-light.svg`
- `pi-coding-agent.svg`

The names and logos belong to their respective owners. This repository only
provides copies sized and packaged for documentation use; it is not affiliated
with or endorsed by those owners.
