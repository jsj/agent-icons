# Agent icons

A small, public collection of coding-agent logos for use in GitHub READMEs.

## Usage

Use an immutable jsDelivr URL pinned to a commit:

```html
<img src="https://cdn.jsdelivr.net/gh/jsj/agent-icons@COMMIT/claude.svg" width="18" height="18" alt="Claude">
```
